# ひだまりパズル（試作）
時間制限なし、手数制限のある7×7マッチ3。5色、3面。スワイプか隣同士の2タップで交換。
4つで一列、5つで色消し、交差消しで周囲ボム。縞ピースは同色マッチで発動、虹ピースは隣と交換して発動する。特殊ピースの誘爆、落下連鎖、目標色の収集。無効交換は手数を使わず戻り、消せる場所がなければ自動で並べ直す。ヒントは手動。盤面と進行はブラウザに保存。ミュート可能な合成効果音。外部アセットなし。

`node test.cjs` : 90ゲーム・636合法ターン、盤面生成、連鎖、目標、保存、4消し・5消し・虹の色指定を検証。開発用の先読み選択で全90ゲームをクリアしたが、人間向け難易度を保証するものではない。
`node ui-test.cjs` : 疑似DOMとネイティブCanvasで実入力、アニメーション、無効交換、取消、ヒント、ヘルプ、ミュート、リサイズ、再開を検証。UIテストには環境にある @napi-rs/canvas が必要。
`node build.cjs` : 単独配布可能な hidamari.html を作成。

実ブラウザ・スマホ実機での表示、タッチ、音声出力は未検証。Canvas画像を目視確認。

## v2 落下中の操作
落下中も、着地済みで消去予約のないピース同士を交換できる。単なる入力予約ではなく、その時点の盤面で即座に次の手を実行し、未消化の連鎖を再計算する。既に動いているピースの見た目の落下は継続。消えかけ・落下中のピースは入力対象から外す。目標達成後と残り0手の追加操作は受け付けない。セーブは最後に確定した計算結果を記録。
`node concurrent-test.cjs` で落下中の実入力、再計算結果の一致、無効操作で連鎖が途切れないこと、手数の二重消費がないことを確認。

## v3 FREE / チェインへの追加入力
起動時は時間・手数制限なしのFREE。残り手数欄をCHAIN表示へ変更。目標を集めると次の目標に切り替わり、そのまま続行する。旧手数モードの保存とは別キー `hidamari-free-v1` を使う。
交換・消去・落下の演出中も、動いていない別のピースで即座に次の交換を実行できる。消去演出中はその消去を計上済みの落下先盤面を使い、同じピース・回収数を再消去しない。既存の消しに次の消しを足して、チェイン数と倍率を引き継ぐ。消えかけ・実際に落下中のピース自体は動かせない。
`node free-test.cjs`：100手以上継続、目標自動切替、交換・消去・落下の各演出中の追加入力、得点・収集数・操作回数の一致、再開を確認。旧 ui-test/concurrent-test は旧手数モード用。`node test.cjs` は旧ルールの回帰検証として継続利用可能。

## v4 操作停止なし
盤面の消去・補充を1波ずつ即時確定し、操作できる49マスを常に埋める。落下の長距離移動と消去完了待ちはなくし、補充先での短い弾み・粒子・光線を独立した演出として重ねる。交換中・消去中・補充中という入力ロックはない。自動連鎖の続きは短い間隔で処理するが、指を置いたりピースを選んでいる間は盤面を固定して指の下のピースが勝手に変わらないようにする。入力は先送りせずその場で実行する。
`node live-test.cjs`：アニメーションtickを挟まず100回の有効交換を即実行、常に49マスが選択可能、押したまま連鎖予定時刻を越える入力、連鎖途中の正確な得点・回収数、保存再開を検証。v1〜v3のUIテストは旧演出仕様用。

## v5 モーションを戻す
交換は140ms、落下は移動距離に応じて210〜440ms。ピースごとの独立した移動座標で描き、次の操作でその時点の位置から動きを継続する。消去ピースにも短い交換と消失の残像を残す。自動連鎖の次の消しは落下を見せる間隔を取るが、その間も入力をロックしない。ヒット判定は描画中の位置を使用し、タップを始めたピースを追跡する。選択枠も移動位置を追う。視覚効果軽減設定では移動を省略。
`node motion-test.cjs`：交換残像、落下座標の変化、移動座標を狙った即時スワイプ、押下中の入力、着地、保存再開を検証。ブラウザ実機は未確認。デザインはv4のままで変更しない。

## v6 絵柄切替
右上の「フルーツ ⇄ / どうぶつ ⇄」で、くっきりしたフルーツ・動物の2種類を切り替える。切替はピースの色番号に対応する絵だけを変更し、盤面・乱数・得点・連鎖・移動位置・選択状態は変更しない。目標欄にも同じ絵を表示。選択は `puzzle-skin` に保存。`skins.js` は比較サンプルと同じ描画を使用し、目標アイコンも同じ描画から作成したデータURL。
`node skin-test.cjs`：両スキンの実描画、目標の対応、移動中の切替、進行状態・座標・得点・連鎖の維持、設定の保存再開を確認。`node motion-test.cjs` でも移動操作の回帰検証。ブラウザ・スマホ実機は未検証。
