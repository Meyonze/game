# ひだまりパズル（試作）
時間制限なし、手数制限のある7×7マッチ3。5色、3面。スワイプか隣同士の2タップで交換。
4つで一列、5つで色消し、交差消しで周囲ボム。縞ピースは同色マッチで発動、虹ピースは隣と交換して発動する。特殊ピースの誘爆、落下連鎖、目標色の収集。無効交換は手数を使わず戻り、消せる場所がなければ自動で並べ直す。ヒントは手動。盤面と進行はブラウザに保存。ミュート可能な合成効果音。外部アセットなし。

`node test.cjs` : 90ゲーム・636合法ターン、盤面生成、連鎖、目標、保存、4消し・5消し・虹の色指定を検証。開発用の先読み選択で全90ゲームをクリアしたが、人間向け難易度を保証するものではない。
`node ui-test.cjs` : 疑似DOMとネイティブCanvasで実入力、アニメーション、無効交換、取消、ヒント、ヘルプ、ミュート、リサイズ、再開を検証。UIテストには環境にある @napi-rs/canvas が必要。
`node build.cjs` : 単独配布可能な hidamari.html を作成。

実ブラウザ・スマホ実機での表示、タッチ、音声出力は未検証。Canvas画像を目視確認。

## v2 落下中の操作
落下中も、着地済みで消去予約のないピース同士を交換できる。単なる入力予約ではなく、その時点の盤面で即座に次の手を実行し、未消化の連鎖を再計算する。既に動いているピースの見た目の落下は継続。消えかけ・落下中のピースは入力対象から外す。目標達成後と残り0手の追加操作は受け付けない。セーブは最後に確定した計算結果を記録。
`node concurrent-test.cjs` で落下中の実入力、再計算結果の一致、無効操作で連鎖が途切れないこと、手数の二重消費がないことを確認。
