# TURN BURST — 一手で、殲滅。

時間制限なしのターン制サバイバー。全20エリア、12体のボスを突破するスマートフォン向けのブラウザゲームです。

公開URL: https://meyonze.github.io/game/turn-burst.html?v=12

## 操作

隣の8方向へタップで移動すると、射撃と衝撃波が発動し、生き残った敵が赤い予告どおりに動きます。自分をタップすると、その場で現在の向きへ攻撃。考えている間は時間が進みません。

- 押している間は撃破数・被ダメージ・ボスへのダメージを確認できます。指を移動範囲の外へずらして離すとキャンセル。
- 敵を先に倒すと、その敵の攻撃も消えます。緑の救急箱を踏むとHPが4回復。
- 強化画面は表示後0.35秒を過ぎてから、新しく同じカードを押して離す操作だけを受け付けます。
- キーボードは矢印キー・QWE / ASD / ZXC。Spaceでその場攻撃。強化は1〜3でも選べます。
- 音符ボタンでサウンド設定を開き、戦闘曲／レトロ曲と音のON/OFFを切り替え。各操作と強化を端末内に自動保存し、「続きから出撃」で再開できます。

## 成長とバランス

新しいプレイでは武装は4系統まで。連鎖爆発、多方向射撃、衝撃波、連鎖雷、貫通射撃、追撃ドローン、隕石、炎、凍結から組み合わせを作ります。射撃・衝撃波そのものは初期状態でも使用でき、その強化を取ると1枠を使います。装甲とオーバークロックは別枠です。装備MAX後は極点射撃・予備装甲・部品解析のコア改造を各20ランクまで育てられます。

- 選んだ武装を育てる方式に変更し、全武装が同時に最大になる成長を抑制。
- 主力武装のLV.3覚醒は6面から。覚醒した8方向射撃は3手ごと、他の手は4方向。
- 雷とドローンは2手ごと、隕石は3手ごと。装備欄に次の発動までの手数を表示。
- オーバークロックは12面から。各敵への最初の一撃だけを最大＋3。同じ敵への多段攻撃・誘爆で加算が重ならない。
- 解凍した敵は2手再凍結せず、永久に行動を止め続けることを防止。
- ボスの光る側からは2倍のダメージ。他の側は通常ダメージ。弱点の側は4手ごとに変化し、盤面の外には設定されない。
- 結界兵は凍結無効・炎と誘爆のダメージを軽減。直接射撃で狙う敵として後半に登場。
- 成長を撃破数からXPへ分離。増殖体から分裂した小型敵はスコアになるがXPは得られない。
- エリア突破でHPを全回復。ボス撃破後の補給では追加の強化権を1回獲得。強化が未解禁なら権利を保持。
- 敵の増援は強弱のある波にし、ボス戦中の増援を減らした。敵HP・ボスHPを4系統の武装に合わせて再設定。

## 保存の互換性

保存形式はv4。旧v2・v3も読み込めます。進行・HP・スコア・既存武装を維持し、旧セーブが4系統を超えていた場合も武装を取り上げません。旧オーバークロックは新上限の3へ調整し、発動間隔・凍結・弱点などのバランス変更を適用します。旧セーブの選択待ち強化は権利を残して新しい候補を出し直します。新規プレイから4枠制になります。

## 開発・検証

`dist/engine.js`が乱数シードを持つ戦闘処理、`dist/app.js`がCanvas・操作・画面遷移、`dist/music.js`が戦闘曲の楽譜とWeb Audio音源です。外部アセットや追加パッケージなしで動きます。

```sh
npm test
npm run build
node tests/balance-simulation.cjs
```

`build.cjs`はCSSとJSを埋め込んだ単体の`turn-burst.html`を生成します。テスト補助の`realCanvas: true`オプションだけは任意の`@napi-rs/canvas`を使用します。

自動テスト101件: 戦闘13、操作・描画・音声12、拡張12、誤操作回帰11、新バランス9、緩和・移行4、クリア条件8、音楽6、曲調選択・低音8、攻撃元・最終戦9、コア改造・旧版移行9。攻撃プレビューと結果の一致、20面の進行、4系統の制限、発動間隔、弱点、凍結耐性、セーブ移行などを検証しています。4種類の強化方針でクリア可能性を確認し、後半の強化済み状態でもその場撃ちだけでは敗北し、移動して攻略する方針では突破できるケースを検証しています。これらは人が感じる面白さの評価ではありません。

Canvas画像は目視確認済み。環境のChromium起動制限があるため、ブラウザ全画面・実機タッチ・実音の確認は未実施です。既存のCHAIN FORGEおよびなぞりゲームは変更していません。

## 難易度の緩和（v6）

敵の開幕配置・増援数・同時出現数と成長HPを減らし、射撃・砲撃の間隔を延長しました。1手の被ダメージ上限は3→2。ボスHPを約2割下げ、弱点以外からのダメージ軽減を廃止し、4手ごとに攻撃の休みを入れました。救急箱は4手ごとに出現してHPを4回復、エリア移動では全回復します。旧版の途中セーブには一度だけHP全回復と既存敵のHP緩和を適用し、その後のリロードでは繰り返し適用しません。4武装の制限と0.35秒の誤選択対策は維持しています。

## クリア条件（v12）

通常面は規定手数で増援が終了し、残敵を全滅させてクリアします。ボス面はボスを倒した瞬間にクリア。残った修復体は制御を失って停止し、掃討は不要です。20面もLAST ORIGIN撃破で勝利。停止した残敵に撃破数・XP・撃破スコアは付かず、その面のクリア報酬を一度だけ受け取ります。ボス登場時は従来どおり周囲の敵を退避させます。

旧版でボス撃破後の掃討中に保存していた場合、再開時に補給画面または最終結果へ移行します。ボス撃破数は再加算せず、次回の保存から新形式となります。

## 戦闘BGM（v8）

オリジナル曲「IGNITION」はDマイナー、160 BPM、32小節・48秒のループ。主旋律、動くベース、ストリングス、パワーコード、ドラムを重ね、後半に別のメロディ展開と対旋律を加えています。ボス用「IRON WILL」は168 BPM・約46秒で、同じテーマにキック・刻み・対旋律を追加。ボス登場・撃破時には次の小節で切り替わります。

外部音源・通信は使わず、出撃操作後にWeb Audioで演奏。ミュート、バックグラウンド移行、結果画面では演奏を停止し、再開時の音の重複を防ぎます。効果音は以前の音量に近づけています。戦闘ルールや難易度はv7を維持。

`node tests/render-music.cjs`で通常戦・ボス戦のWAVプレビューを生成できます（この任意の開発用処理だけPythonのnumpy/scipyが必要）。プレビューは実際の演奏指定から波形を合成しますが、ブラウザのフィルター・圧縮処理を完全には再現しません。波形の飽和なし、2周連続演奏で音源ノード数が増え続けないこと、切替・保存済みミュート・バックグラウンド復帰・リトライ・結果画面での停止を自動検証済み。実機での音質・音量の確認は未実施です。

## ベース強化・曲調の選択（v9）

戦闘曲のベースに歪み、減衰するフィルター、短いオクターブのアタックを追加。低域の芯はクリーンなサイン波で残し、中域の倍音も増やしてスマートフォンのスピーカーでも輪郭が出る構成にしました。通常戦・ボス戦の両方に適用しています。

右上の音符から「戦闘・ベース強め」「レトロ・おだやか」を選択できます。レトロ曲「PIXEL AFTERNOON」はCメジャー、104 BPM、16小節・約37秒の別曲。角の取れた矩形波の主旋律、三角波のベースと分散和音、控えめなドラムで演奏し、ボス戦でも穏やかな曲調を保ちます。選択は端末内に保存し、音をOFFにしたまま選曲しても勝手にONにはしません。

設定画面ではタイトル・結果画面からも試聴でき、閉じると試聴を停止。プレイ中は演奏を継続します。切替時は古い音源を止め、曲の頭から再生。何度切り替えてもスケジューラーや音源が増え続けないこと、再起動・バックグラウンド復帰での曲調維持、設定中に移動や強化を誤入力しないことを自動検証しています。WAV書き出しは通常戦・ボス戦・レトロの3曲に対応。実機での試聴は未実施です。

## 攻撃の因果・最終戦・曲の対比（v10）

移動先を押している間は、そのマスを狙う敵にA・B印を付け、敵と移動先を線で結びます。赤線は攻撃が残る敵、緑の×と点線はこの一手で撃破して攻撃を阻止できる敵、青は凍結で停止する敵。盤面下にも同じA・Bと理由を表示し、ボス撃破による全攻撃のキャンセル・装甲による軽減を別々に説明します。合計HP被害は従来どおり上限・装甲を適用した正確な数値です。予告の計算に戦闘のクローンを使用し、実際の撃破・凍結イベントと照合しています。被弾した瞬間にも攻撃元から線を表示します。

20面のLAST ORIGINは、翼・浮遊片・回転する核を持つ専用の姿、FINAL BOSSの登場カット、黄金のHPバーと星空の戦場に変更。HP半分で「核心露出」となり、姿とHP表示が赤紫へ変わり、専用曲も加速します。HP・攻撃力・攻撃パターンなどの難易度はv9を維持しています。演出は次の操作で閉じられ、追加の操作待ちはありません。

戦闘曲の対比は、通常戦「IGNITION」144 BPM・32小節（約53秒）、ボス戦「IRON WILL」184 BPM・16小節（約21秒）の別メロディに変更。ボス登場に合わせて頭から切り替え、歪んだ刻み・ブラス・激しいドラムを加えました。最終戦「THE LAST ORIGIN」は別の主旋律と厚いパッドの176 BPM・32小節（約44秒）。核心露出後は196 BPM（約39秒）になります。「レトロ・おだやか」も通常戦・ボス戦・最終戦で別のメロディに切り替えます。音色と音量は穏やかなまま、ボス戦は短調・120 BPM、最終戦の核心露出後は132 BPMで対比を付けます。

撃破で攻撃を消せる場合と撃ち漏らす場合、接触攻撃、凍結・凍結無効、装甲、ボス撃破キャンセル、計算による状態不変、最終戦の登場・核心露出、曲の即時切替、音源数の上限を検証。Canvas画像は目視確認済み。音源の書き出しで飽和がないことを確認していますが、実機ブラウザの画面全体・タッチ・実音は未確認です。

## ベースをさらに前面へ（v11）

通常戦・ボス戦・最終戦のベースを4層へ変更。歪ませたノコギリ波の持続音、FMによる金属的なうなり、低域の芯、音の頭から残るオクターブ上の倍音を重ねています。中低域の厚みと立ち上がりを増やし、ベースの音量も引き上げました。音源ノードの解放・ミュート・復帰・切替を含む関連23テストを実行し、書き出し波形の飽和を確認しています。プレビューはブラウザのコンプレッサーを再現しない近似音源です。実機での試聴は未実施です。

## ノアの物語と装備MAX後のコア改造（v12）

主人公は廃棄寸前の旧式整備ロボ〈ノア〉。自分を捨てた軌道都市を救うため、回収した部品で武装を組み直します。敵は暴走した都市再生装置ORIGINに支配された修復体。ORIGINは街全体を部品へ還元しようとしており、各区域のボスが敵群を動かす制御核です。タイトル・遊び方・クリア・最終結果で、この設定を説明します。追加の会話待ちや強制説明はありません。

選んだ4系統と補助装備がMAXになった後、12面以降はコア改造が3択に加わります。武装の4枠とは別で、各20ランク。通常の20面プレイで後半も選べる量を用意しました。

- 極点射撃：4手ごとの貫通射撃をランク分強化。発動時は金色の射撃。
- 予備装甲：1ランクごとに最大HP＋1とHP1回復。
- 部品解析：1ランクごとに撃破XP＋5％、撃破スコア＋12％。XPの端数は保存・再開をまたいで蓄積。分裂した敵にはXPを与えません。

既存のボス補給の強化権・XPで選択し、誤タップ防止の0.35秒は共通です。16通りの自動プレイで20面到達と後半のコア改造獲得を確認。従来の「その場撃ちだけでは敗北、移動して攻略すると勝利」のケースも維持できています。実機での面白さ・操作感の評価は未実施です。
