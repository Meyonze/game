# TURN BURST — 一手で、殲滅。

時間制限のない、スマートフォン向けターン制サバイバーのプロトタイプです。

## 遊ぶ

公開URL: https://meyonze.github.io/game/turn-burst.html

隣の8方向のマスをタップすると、移動・武器の一斉攻撃・敵の行動が1回ずつ進みます。自分をタップすると、その場で現在の方向へ攻撃します。操作しない限り、戦闘は進みません。

- 押している間は、撃破数・ボスへのダメージ・被ダメージを事前に確認できます。指を移動できない場所へずらして離すとキャンセル。
- 赤いマスは敵の次の攻撃先です。その敵を先に倒すと、その攻撃も消えます。
- 撃破数で武器を強化。連鎖爆発、多方向射撃、広範囲衝撃波、連鎖雷、強化ランス、追撃ドローン、回復装甲、隕石、炎、凍結の10系統。
- 3エリア目から、主力武器6系統をLV.3「覚醒」へ強化できます。8方向射撃、広範囲の連鎖爆発など、攻撃そのものが大きく育ちます。
- 緑の救急箱を踏むとHPが3回復。
- 全5エリア。接敵宙域→鉄壁の門→増殖庭園→雷鳴回廊→王の領域へ進みます。2・4・5エリアには、それぞれ異なるHP・攻撃予告・外見のボスが登場します。
- 突進兵、分裂する増殖体、十字砲撃の砲台を追加。エリアごとに敵の構成と強さが変わります。
- エリア突破でHPを3回復し、武器強化を1回獲得。武器とスコアを引き継いで次のエリアへ進みます。
- キーボード: 矢印キー、QWE / ASD / ZXC、Spaceでその場攻撃。強化画面は1〜3でも選択できます。
- BGM・効果音は上部の音符ボタンで切り替え。サウンド設定とベストスコアは端末内に保存します。
- 各操作・強化・エリア移動を自動保存。ページを開き直すと「続きから出撃」で再開できます。ブラウザが保存を制限している場合は、その場でのプレイを継続できます。

## 構成

- `dist/engine.js`: 乱数シードを持つターン制シミュレーション。プレビューは複製した状態で同じ戦闘処理を実行します。
- `dist/app.js`: Pointer Events、Canvas描画、Web Audio、画面遷移。
- `dist/index.html` / `dist/style.css`: 縦画面のUI。盤面を残りの表示領域に収め、待機・プレイでサイズを変えません。
- `build.cjs`: CSS/JSを埋め込んだ、外部依存のない `turn-burst.html` を生成します。
- `tests/`: 戦闘13件、操作・描画・音声12件、拡張要素12件。Node標準ライブラリで実行できます。

```sh
npm test
npm run build
```

通常の実行・テストに追加パッケージは不要です。テスト補助の `realCanvas: true` オプションだけが、任意の `@napi-rs/canvas` を使用します。

プレビューと実行結果の一致、連鎖爆発、予告のキャンセル、敵の重なり、ボスの当たり判定、強化選択、クリア・敗北・再挑戦、タップ保留・キャンセル・多重入力、座標変換、音声の開始・停止を自動検証しました。追加した敵・武器・覚醒・補給・保存再開も検証しています。20シードで全5エリアを最後まで進め、3ボスを倒してクリアできることを確認しています。

Canvas部分は画像に描画して目視確認しています。検証環境のChromiumが起動制限で終了したため、ブラウザ全画面でのレイアウト・実機タッチ・実音の確認は未実施です。自動プレイ結果は人が感じる面白さの評価には使っていません。
