# TURN BURST — 一手で、殲滅。

時間制限なしのターン制サバイバー。全20エリア、12体のボスを突破するスマートフォン向けのブラウザゲームです。

公開URL: https://meyonze.github.io/game/turn-burst.html?v=7

## 操作

隣の8方向へタップで移動すると、射撃と衝撃波が発動し、生き残った敵が赤い予告どおりに動きます。自分をタップすると、その場で現在の向きへ攻撃。考えている間は時間が進みません。

- 押している間は撃破数・被ダメージ・ボスへのダメージを確認できます。指を移動範囲の外へずらして離すとキャンセル。
- 敵を先に倒すと、その敵の攻撃も消えます。緑の救急箱を踏むとHPが4回復。
- 強化画面は表示後0.35秒を過ぎてから、新しく同じカードを押して離す操作だけを受け付けます。
- キーボードは矢印キー・QWE / ASD / ZXC。Spaceでその場攻撃。強化は1〜3でも選べます。
- 音符ボタンでBGM・効果音を切り替え。各操作と強化を端末内に自動保存し、「続きから出撃」で再開できます。

## 成長とバランス

新しいプレイでは武装は4系統まで。連鎖爆発、多方向射撃、衝撃波、連鎖雷、貫通射撃、追撃ドローン、隕石、炎、凍結から組み合わせを作ります。射撃・衝撃波そのものは初期状態でも使用でき、その強化を取ると1枠を使います。装甲とオーバークロックは別枠です。

- 選んだ武装を育てる方式に変更し、全武装が同時に最大になる成長を抑制。
- 主力武装のLV.3覚醒は6面から。覚醒した8方向射撃は3手ごと、他の手は4方向。
- 雷とドローンは2手ごと、隕石は3手ごと。装備欄に次の発動までの手数を表示。
- オーバークロックは12面から。各敵への最初の一撃だけを最大＋3。同じ敵への多段攻撃・誘爆で加算が重ならない。
- 解凍した敵は2手再凍結せず、永久に行動を止め続けることを防止。
- ボスの光る側からは2倍のダメージ。他の側は通常ダメージ。弱点の側は4手ごとに変化し、盤面の外には設定されない。
- 結界兵は凍結無効・炎と誘爆のダメージを軽減。直接射撃で狙う敵として後半に登場。
- 成長を撃破数からXPへ分離。増殖体から分裂した小型敵はスコアになるがXPは得られない。
- エリア突破でHPを全回復。ボス撃破後の補給では追加の強化権を1回獲得。強化が未解禁なら権利を保持。
- 敵の増援は強弱のある波にし、ボス戦中の増援を減らした。敵HP・ボスHPを4系統の武装に合わせて再設定。

## 保存の互換性

保存形式はv3。旧v2（5・10エリア版）も読み込めます。進行・HP・スコア・既存武装を維持し、旧セーブが4系統を超えていた場合も武装を取り上げません。旧オーバークロックは新上限の3へ調整し、発動間隔・凍結・弱点などのバランス変更を適用します。旧セーブの選択待ち強化は権利を残して新しい候補を出し直します。新規プレイから4枠制になります。

## 開発・検証

`dist/engine.js`が乱数シードを持つ戦闘処理、`dist/app.js`がCanvas・操作・Web Audio・画面遷移です。外部アセットや追加パッケージなしで動きます。

```sh
npm test
npm run build
node tests/balance-simulation.cjs
```

`build.cjs`はCSSとJSを埋め込んだ単体の`turn-burst.html`を生成します。テスト補助の`realCanvas: true`オプションだけは任意の`@napi-rs/canvas`を使用します。

自動テスト69件: 戦闘13、操作・描画・音声12、拡張12、誤操作回帰11、新バランス9、緩和・移行4、全滅クリア8。攻撃プレビューと結果の一致、20面の進行、4系統の制限、発動間隔、弱点、凍結耐性、セーブ移行などを検証しています。4種類の強化方針でクリア可能性を確認し、後半の強化済み状態でもその場撃ちだけでは敗北し、移動して攻略する方針では突破できるケースを検証しています。これらは人が感じる面白さの評価ではありません。

Canvas画像は目視確認済み。環境のChromium起動制限があるため、ブラウザ全画面・実機タッチ・実音の確認は未実施です。既存のCHAIN FORGEおよびなぞりゲームは変更していません。

## 難易度の緩和（v6）

敵の開幕配置・増援数・同時出現数と成長HPを減らし、射撃・砲撃の間隔を延長しました。1手の被ダメージ上限は3→2。ボスHPを約2割下げ、弱点以外からのダメージ軽減を廃止し、4手ごとに攻撃の休みを入れました。救急箱は4手ごとに出現してHPを4回復、エリア移動では全回復します。旧版の途中セーブには一度だけHP全回復と既存敵のHP緩和を適用し、その後のリロードでは繰り返し適用しません。4武装の制限と0.35秒の誤選択対策は維持しています。

## クリア条件の統一（v7）

通常面は規定手数で増援だけが終了し、残っている敵を全滅させてからクリアします。ボス面はボス撃破で増援が止まり、残敵も全滅させてクリア。最終面も同じ条件です。増援終了後はHUDに「残り○体」を表示し、分裂した敵も最後まで倒す必要があります。ボス撃破数はその場で一度だけ加算し、残敵処理中の保存・再開でも重複しません。ボス登場時の敵も削除せず周囲の空きマスへ移動します。
