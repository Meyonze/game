# 蒼界の双機 — AETHER PAIR v2

**青いマスに動かすだけ。となりを自動攻撃、ふたりで囲めば連携。**

公開URL: https://meyonze.github.io/game/aether-pair.html?v=2

初版から操作とルールを作り直しました。7×8マス、2機、全6面。最初の面は、光る移動先を2回タップして自動攻撃と連携を体験します。

## ルール

- 機体を選んで青いマスへ移動。上下左右に2マスまで動けます。
- 移動すると、上下左右の敵全員に自動で1ダメージ。同じ敵に2機が隣接していれば、その攻撃は連携になり2ダメージ。
- 2機を1回ずつ動かすと敵の番。赤い×に1ダメージの攻撃が来ます。敵を先に倒せば、その攻撃は消えます。
- 敵を全滅させればクリア。最終面はネブラ撃破で終了。どちらかの機体のHPが0で失敗。

攻撃対象や武器の選択、行動予約や実行ボタン、護衛対象、装甲、防御、押し出し、特殊地形はありません。両機は同じ移動・攻撃ルール。敵の攻撃は全員が現在の赤い×へ撃ってから、雲獣だけが近づきます。直線砲はその場から予告した列を攻撃し、ネブラは縦横の十字へ攻撃します。壁は移動と射線を遮断します。

攻撃が当たる場所、同時に叩ける敵の数、2機が隣接できる位置、動かす順番が判断の中心です。

## 操作

基本は移動先をタップするだけ。移動後は未行動の機体へ自動で切り替わります。別の機体から動かしたければ機体か上のカードをタップ。「その場で攻撃」または現在のマスのタップでも行動できます。

長押し・ドラッグ中は移動と攻撃の結果を表示。範囲外へ指を逃がすかキャンセルすると行動しません。「一手戻す」は敵の攻撃や移動も含めて直前の行動前へ戻します（最大16手）。1/2で機体選択、Spaceでその場攻撃、Escapeで一手戻す。

各行動を確定した時点で端末内へ保存。アニメーション中に再読込しても二重実行せず、1機だけ動かした途中の状態にも復帰します。ルールが異なる初版のセーブとは分離し、v2は冒頭から始まります。音符でBGM・効果音をまとめて切替。

## 検証とビルド

```sh
npm test
npm run build
```

単体の`aether-pair.html`を生成します。ブラウザで外部素材・ライブラリ・通信は不要。任意のCanvas画像出力だけ`@napi-rs/canvas`を使用します。

自動テスト36件: エンジン15、操作・保存・音声14、6面の攻略と全編タップ進行7。自動範囲攻撃、連携、敵ターン移行、予告と実行の一致、撃破による攻撃の取消、壁、待機攻撃、一手戻す、途中保存・復帰、連打・2本指・背景停止を確認しています。

全6面の合法な攻略手順を`artifacts/campaign-simulation.json`に収録。探索補助は`node tests/simulate-campaign.cjs`。攻略可能性の確認であり、人が感じる面白さや直感性の評価ではありません。Canvas画像は目視確認済み。実機ブラウザ全体のレイアウト、タッチ、実音は未確認です。
