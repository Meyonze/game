# 蒼界の双機 — AETHER PAIR

時間制限なしの、2機による小さな戦術シミュレーション。TURN BURSTと別のゲームとして制作した初期プロトタイプです。

公開URL: https://meyonze.github.io/game/aether-pair.html?v=1

雲海に浮かぶ島々を結ぶ風見灯を、帆装機乗りユナとセナが守る物語。盤面は9×11、全6作戦。数値を積み上げる強化・成長を入れず、2機の位置取り、行動順、敵の予告を使う判断に絞っています。

## 遊び方

1. 盾機アステルか砲機リュミエを選び、青いマスへ移動先を指定。
2. 射程内の敵をタップして攻撃を予約。攻撃の代わりに「防御で予約」も可能。
3. もう1機も予約し、「2機の行動を実行」を押すと、予約順に味方、その後数字順に敵が行動。
4. 確定前なら「戻す」で最後の予約を取り消せます。予約済み機体のカードを押すと、その予約以降を組み直します。

敵を長押しすると、攻撃を予約せず予告を確認できます。敵の赤い予告、予定位置、HP予測を見比べてください。移動だけで攻撃未選択の間は仮予測で、2機の予約後が実行予測です。命中・会心の抽選はありません。

- **盾機**: 移動3。隣接打撃3、突き押し2＋1マス移動。押せないと衝突で追加2。防御は自身の被害−2、隣の砲機を−1、隣の風見灯を−2。
- **砲機**: 移動3。射程2〜4の射撃3。盾機が敵に隣接し、反対側から撃つと装甲無視の「双機挟撃」7。貫通射撃は直線2〜6マスへ3、味方も巻き込みます。
- **先読み**: 敵の狙いはラウンド開始時に決まり、プレイヤーの移動先を後出しで追尾しません。押された敵の発射位置と、他の機体に阻まれる接近位置は変化し、予測へ反映されます。
- **同士討ち**: 敵の攻撃は敵にも命中。先に撃破された敵は行動しません。押して射線へ入れたり、敵の攻撃を別の敵に受けさせたりできます。
- **地形**: 壁は移動と射線を遮断。防護床は機体への被害−1。帯電雲は敵の行動後に2ダメージ。
- **勝敗**: 2機か風見灯を失うと敗北。全滅させると勝利。最終作戦のみ、ネブラのHPを0にすれば残りの敵がいても終了。

途中のラウンドと作戦記録を端末内に保存します。予約は保存せず、確定したラウンドの結果を保存するため、アニメーション中の再読込でも二重実行しません。1/2で機体選択、Gで防御予約、Enterで実行、Escapeで最後の予約取消。音符でBGMと効果音をまとめて切替。

## 開発

```sh
npm test
npm run build
```

ビルドはCSS・JSを含む単体ファイル`aether-pair.html`を生成。ブラウザ実行時の通信・外部素材・ライブラリは不要です。`dist/index.html`も単体の静的サイトとして利用できます。テスト用の任意Canvas画像出力だけ`@napi-rs/canvas`を使います。

自動テスト36件: エンジン16、操作と音声13、作戦攻略・全編タップ進行7。予約と実行の一致、順番依存、挟撃、押し出し、同士討ち、敵行動の取消、遮蔽物、防御、味方への貫通被害、保存復帰、2本指や連打、バックグラウンド停止、6作戦すべてのクリアを検証します。

`artifacts/campaign-simulation.json`には全6作戦の合法なクリア手順を収録。検証用であり、自動プレイ機能ではありません。探索による攻略可能性は確認しましたが、人が感じる難易度や面白さは未評価です。Canvas画像は確認済み。実機ブラウザ全体のレイアウト、タッチ、実音は未確認です。
