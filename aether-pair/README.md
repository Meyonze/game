# ネコと鉄の灯台 — ふたりの一手

短い一戦で、2匹の行動・位置・共有バッテリーを使い分けるブラウザ戦術ゲーム。時間制限なし。旧 Aether Pair v1/v2 と同じ公開URLを更新する v3。TURN BURST など他作品は変更しない。

## 世界と目的

港町の修理屋のトトとミオが、暴走して警備ロボを操る灯台を止めに行く。
- トト：茶トラ、赤い作業着、大きな盾とハンマー。前衛。
- ミオ：灰色ネコ、青い帽子、真鍮の工具砲。遠距離支援。
- 巡回ロボ／重警備ロボ：赤いレンズの警備機械。
- 灯台の制御炉：HP12。壊せば周囲の敵が残っていても勝利。

背景は港の桟橋、障害物は木箱。キャラクターは Canvas、開始画面はインライン SVG。外部画像・音声・フォント不要。

## 操作

1. トトまたはミオを選び、青いマスで移動を試す。上下左右2マスまで、移動しなくてもよい。
2. 攻撃／大技／守ってためるを選ぶ。攻撃は金色の敵をタップ。
3. 下の確定ボタンで実行。移動と標的は確定前なら何度でも変更可能。

2匹が1回ずつ行動すると敵の番。行動の順番は自由。連携だけは2匹の行動を一度に使う。一手戻すは敵の番・消費バッテリーも戻す。再開は確定済みの状態から。前バージョンのセーブは別キーで保持し、新ルールに変換しない。

## ルール

- 通常攻撃：無料、2ダメージ。トトは上下左右の隣。ミオはマンハッタン距離2〜4。ミオは斜め方向も射撃でき、一直線に壁がある場合は遮られる。機体は射線を遮らない。
- 大技：共有バッテリー2。トトは隣の全敵に3、ミオは1体に4。
- 守ってためる：バッテリー+1。次の敵の番の各被弾を1軽減。トトは自分と隣の味方、ミオは自分のみ。軽減は重複しない。
- コンビ技：バッテリー3、8ダメージ。2匹とも未行動で、トトが標的に隣接し、ミオの射程内にいること。2匹とも行動終了。選択した1匹だけは確定前に移動できる。もう1匹の位置も前のターンから準備する。
- バッテリーは初期2、毎ターン+2、上限5。持ち越せる。
- 敵の移動予定・攻撃方向はターン開始時に固定。敵は矢印の先へ移動後に攻撃。移動先が埋まっていると現在地から攻撃。
- 灯台の砲撃は最初の味方・敵・壁で止まる。警備ロボにも当たる。敵を倒すとその攻撃は消えるが、砲撃の射線が開く場合がある。
- 予測と敵ターン本番は同じ解決処理を利用。「この配置で敵の番なら」は、残る味方の行動は仮定せず、その時点の配置で算出。確定直前の行動内容も反映。
- どちらかのHPが0で敗北。敵の攻撃順は配置順で固定。

## 構成

本番1戦 + 任意の操作練習1戦。ステージ増加や成長システムは入れず、この一戦の判断を試す。

`dist/engine.js`: 決定論的ルール、予測、保存。`dist/app.js`: 操作、描画、Web Audio。`dist/index.html` / `style.css`: 画面・キャラクター紹介。

```
npm test
npm run build
```

生成される `aether-pair.html` を GitHub Pages に公開。モジュール版は `dist/index.html` を通常の静的サーバーで開く。

## 検証

34ケース（Nodeの標準ランナーでは3ファイルと表示）。共有資源、射程、防御、連携、敵砲の遮蔽／同士討ち、予測一致、勝敗、保存、確定前操作、戻す、入力連打、途中再開、背景停止、音切替、小さな描画領域を確認。

`tests/search-v3.cjs` は開発用の有限幅探索。結果は `artifacts/tactical-lines.json` に保存し、テストが合法手とクリアを再生する。自動探索は本体に含まれない。異なる初手で3ターン・HP7/5、5ターン・HP9/6などの勝ち筋を確認。これは最適性・面白さ・人間向けの難易度の証明ではない。

ネイティブCanvasの画像を目視確認し、疑似DOMの入力で本番と練習を完走。実ブラウザ・スマートフォン実機のレイアウト／タッチ／音声出力は未検証。

音はWeb Audioによる合成BGM・効果音。最初の操作で有効化、画面右上でオフ。OSの視覚効果軽減設定を尊重する。
